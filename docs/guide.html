郵送買取のながれと注意点

特定の買取店の話ではなく、郵送買取そのものの一般的なしくみをまとめたページです。実際のキャンセル可否・補償・振込までの日数などは店によって違うので、利用する店の説明ページも必ず確認してください。

郵送買取とは

店頭に持ち込まず、カード・BOXを箱に詰めて店へ送り、店が中身を見て金額を決め、その金額を口座に振り込んでもらう買取の方法です。全国どこに住んでいても、店頭のある都市まで行かずに売れるのが利点です。

一般的なながれ

  1. 申し込み — 店のサイトやLINEから、買取の申し込みをします。本人確認書類の提出が必要な店がほとんどです（古物営業法という法律で決まっているためで、怪しい手続きではありません）。
  2. 梱包・発送 — 案内に沿って梱包し、指定の送り状・宅配便で送ります。着払いに対応している店も多いです。
  3. 査定 — 店に届いたあと、中身を確認して金額が決まります。届いてから数日かかることがあります。
  4. 金額の連絡 — 決まった金額の連絡が来ます。ここで、申し込み時に見ていた「買取価格表」の金額と違うことがあります（下の「注意しておきたいこと」参照）。
  5. 承諾・入金 または キャンセル — 金額に納得すれば承諾し、後日振り込まれます。納得できなければ、キャンセルして返送してもらうこともできます（キャンセル自体は違約金なしの店が多いですが、返送料は自己負担になる場合があります）。

注意しておきたいこと

  • 価格表の金額は「確定」ではありません。 申し込み時点の目安で、実際の状態（傷・シュリンクのゆるみ・パッケージの傷みなど）を見て変わることがあります。特に安すぎる／高すぎる価格表には注意してください。
  • キャンセルできるか、返送料は誰が払うかを、申し込み前に確認しましょう。 店によって条件が違います。
  • 輸送中の破損・紛失の補償があるか。 高額なBOXほど、追跡できる発送方法・補償のある宅配便を選ぶと安心です。
  • いわゆる「不当な減額」に気をつける。 明らかな理由なく、連絡していた金額から大きく下げられた場合は、その場で承諾せず、理由を確認しましょう。返送してもらう選択肢も忘れずに。
  • 振込までの日数を確認する。 承諾してから即日〜数日と、店によって差があります。
  • 梱包は、多少厚めに。 シュリンク付きBOXは、箱の角がつぶれるとシュリンクも傷みやすいです。緩衝材を入れて、箱の中で動かないようにしましょう。
  • 古物商許可の番号が、サイトに書いてあるか確認する。 中古品の売買には、公安委員会の許可が必要です。番号が見当たらない・会社の所在地が書かれていない店は、避けたほうが無難です。
  • 個人情報の扱い。 本人確認書類は、買取に必要な範囲でしか使われないはずです。提出前に、プライバシーポリシーへの記載があるかも見ておくと安心です。

このページは一般的な内容の紹介であり、特定の店の取引条件を保証するものではありません。最終的な条件は、必ず利用する店自身の説明・規約でご確認ください。
